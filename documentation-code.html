Persistent Style Switching System

Rather than duplicating HTML structures across eras, the website implements a non-destructive runtime theme-swapping system. below the <header> of each page, a single stylesheet tag carries class="bar-style",invoking a function in JavaScript attaching event listeners to every .bar-style:

Persistence across page transitions: When a user navigates through different sections of this website, base.js reads localStorage.getItem("userStyle") before DOM rendering completes, preserving the chosen era.

02. Data Decoupling via JSON

A core architectural decision was the complete separation of content, metadata, and cartographic geometry from static markup into external JSON repositories (dati_tour.json, mappa.geojson, and spostamenti.json).

Data Decoupling

HTML files maintain an immaculate structural skeleton without dense walls of hardcoded prose. In this way editors can refine narrations or add metadata without editing HTML markup.

Single source files

Itinerary data are shared between the narrative texts and the map page. Dynamic JSON nesting allows each scene to store information between 3 target audiences (normal, child, scholar) and 4 content granularities (text-less, text-standard, text-more, text-didyouknow), or explore different coordinates.

04. Metadata in narratives

Every cinematic scene incorporates metadata organised using standard web ontologies:

  • Schema.org used for the cinematic contexts such movie titles, directors and shot information.

  • CIDOC CRM and Schema.org gives infomration about the architectural heritage and coordinates and dates datas..

  • Dublin Core (dcterms)records the language attribuet and the credits of this project

These properties are fetched dynamically and rendered inside specific modal overlays, ensuring that viewers can inspect technical filmmaking choices both with with architectural data.

05. Technical implementations & architectural best practices

Some of the technical coding choices we have done in order to to enrich the visual presentation without polluting the HTML DOM are:

::before and ::after

This pseudo-elements are used to add content in specific stylesheet when belonging to specific eras

.active buttons state

Is handled by the JavaScript to manage selected states of the consistently without writing redundant code on every button element

Fixed Viewport

Standard desktop displays and modern laptops provide typical viewport heights between 768px and 1080px. We have chosen to fix some height limit to 560px in order to ensures the entire fit of the content without requiring disruptive scrolling.
